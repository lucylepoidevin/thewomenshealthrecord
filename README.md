# The Women's Health Record

Original analysis of public data on sex disparities in medicine, told as scrolling data stories.

- `site/` — Vite + React + Tailwind + D3 front end, deployed to GitHub Pages.
- `pipeline/` — Python scripts that fetch FDA / openFDA data and write the JSON the site reads. See `pipeline/README.md`.

Run locally:

```bash
cd site && npm install && npm run dev
```
